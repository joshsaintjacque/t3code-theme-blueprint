01

Motion that means something.

Every animation in Blueprint is tied to real app state. If nothing is running, nothing moves. That's the whole trick: a glance tells you whether your agent is still at work.

04

On your screen in about ten seconds.

Blueprint is a single JSON file: colors plus a little CSS. Add it from inside the app, or set it from the terminal.

From the app

No terminal needed.

  1. Copy the theme
    Download file
  2. Open the theme pickerSettings › Appearance › Add theme
  3. Paste it, or choose the fileThen add it. Blueprint is selected for you.

From the terminal

Downloads the theme, then publishes it and switches to it in one step.

$ curl -fsSL -o blueprint.json \
    https://joshsaintjacque.github.io/t3code-theme-blueprint/blueprint.json
$ ~/.t3/bin/t3 theme set blueprint.json

This sets the theme for the whole environment, so every client connected to it switches. Switch back anytime in Settings › Appearance.

Tested on T3 Code v0.1.10 (nightly). Want your own variant? The theme is generated by source/build.py.
